## 📑 Lab Activities Overview

### 1. Activity 1 – Linear Regression
- **Directory:** [`Activity-1-LinearRegression`](./Activity-1-LinearRegression/)
- **Notebook:** [`Activity-1-Linear Regression.ipynb`](./Activity-1-LinearRegression/Activity-1-Linear%20Regression.ipynb)
- **Dataset:** [`5_Linear_Regression_Dataset_Exercise_2.csv`](./Activity-1-LinearRegression/5_Linear_Regression_Dataset_Exercise_2.csv)
- **Description:** Implementation of Linear Regression using `scikit-learn`. Includes dataset loading, exploratory data analysis, train-test splitting, model training, visualization of regression line using `matplotlib`, and evaluation using metrics such as MAE, MSE, and $R^2$ score.

---

### 2. Activity 2 – Logistic Regression
- **Directory:** [`Activity-2-LogisticRegression`](./Activity-2-LogisticRegression/)
- **Notebook:** [`Activity-2-Logistic Regression.ipynb`](./Activity-2-LogisticRegression/Activity-2-Logistic%20Regression.ipynb)
- **Dataset:** [`6_Logistic_Regression_Dataset_Exercise_2.csv`](./Activity-2-LogisticRegression/6_Logistic_Regression_Dataset_Exercise_2.csv)
- **Description:** Implementation of Binary Classification using Logistic Regression in `scikit-learn`. Includes dataset preprocessing, model training, confusion matrix visualization with `seaborn`, and evaluation using Accuracy, Precision, Recall, and Classification Report.

## 🛠️ Prerequisites & Setup

To run the Jupyter Notebooks locally, install the required Python libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### Launching Notebooks
1. Clone the repository:
   ```bash
   git clone https://github.com/Santhosh2006-09/23CSE301-ML-Lab.git
   cd 23CSE301-ML-Lab
   ```
2. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
3. Navigate to any activity directory and open the `.ipynb` notebook.
