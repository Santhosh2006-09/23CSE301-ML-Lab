## 📊 Project Details

- **Language:** Python 3.14.4
- **Libraries:** pandas, scikit-learn, matplotlib, numpy
- **Dataset:** 10 samples with 4 features
- **Model:** Linear Regression
- **Features:** Height, Age, Gender
- **Target:** Weight
